## S3 Service

### Aim
To create a cloud instance in the AWS server for creating cloud storage (S3 Bucket).  

### Procedure
1. Sign in to **AWS Console**  
2. Navigate to **S3**  
3. Click **Create Bucket**  
4. Enter a unique bucket name  
5. Choose **Region (us-west-2)**  
6. Click **Create**  

### Applications
- Data storage  
- Website hosting  
- Backups  
- Analytics  
- Machine Learning dataset storage

## EC2 Service

### Aim
To create a virtual machine instance in the AWS server using EC2.  

### Procedure
1. Open **AWS Console**  
2. Go to **EC2**  
3. Click **Launch Instance**  
4. Choose an **Amazon Machine Image (AMI)**  
5. Select **Instance Type:** t2.micro  
6. Configure and launch using a **key pair**  


### Applications
- Web hosting  
- Machine Learning model deployment  
- Database hosting  
- Backup services  
- Game server hosting

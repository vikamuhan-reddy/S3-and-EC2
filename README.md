## S3 Service

**Aim:** To create a cloud instance in the AWS server for creating cloud storage (S3 Bucket).  
**Procedure:** Sign in to AWS Console → Navigate to S3 → Create Bucket → Name it uniquely → Choose Region (us-west-2) → Click Create.  
**Applications:** Data storage, website hosting, backups, analytics, and ML dataset storage.

## EC2 Service

**Aim:** To create a virtual machine instance in the AWS server using EC2.  
**Procedure:** Open AWS Console → Go to EC2 → Launch Instance → Choose AMI → Select t2.micro → Configure and Launch with key pair.  
**Applications:** Hosting, ML model deployment, database hosting, backups, and game servers.
